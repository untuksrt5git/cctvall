Pengaturan Dinding CCTV

Di HP yang menjalankan CloudCam gunakan http://127.0.0.1:8889. Dari perangkat lain, gunakan IP HP server, misalnya http://192.168.1.26:8889. Jangan isi port dashboard 8090 di sini.

Satu kamera per baris: Nama | path utama | path ringan (opsional). Hik-Connect: RT 05 - Pintu | cam/D77739233_1 | cam/D77739233_1/sub. Tuya: Tuya 1 | rtsp/tuya1. Grid menggunakan path ringan; layar penuh menggunakan path utama.
